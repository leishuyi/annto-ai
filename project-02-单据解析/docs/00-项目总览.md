# annto 多模态物流单据解析引擎 — 项目文档

## 概述
一套模型搞定物流场景所有纸质单据的结构化识别，覆盖 5 大类。

## 解析管线

输入 → 图像预处理(缺) → 文档分类 → OCR → 字段提取 → 置信度校准(缺) → 输出

## 技术选型与方案对比

### OCR 引擎

| 指标 | **PaddleOCR** ✅ | Tesseract 5 | 阿里云OCR |
|------|-----------------|-------------|-----------|
| 中文识别率 | **98.5%** | 85% | 99% |
| 私有化部署 | ✅ | ✅ | ❌ |
| 自定义训练 | ✅ | ✅ | ❌ |
| 成本 | 免费 | 免费 | 按量 |
| **决策**: MVP 用 mock，生产用 PaddleOCR（可私有部署，可自定义训练物流模型） |

### 文档分类

| 方案 | 准确率 | 维护成本 | 结论 |
|------|--------|---------|------|
| **关键词匹配** ✅ | ~70% | 低 | MVP，够用 |
| LLM 分类(Qwen-VL) | ~95% | 低 | 生产目标 |
| 视觉 Transformer | ~97% | 高 | 长期演进 |

### 多模态模型

| 方案 | 部署方式 | 成本 | 结论 |
|------|---------|------|------|
| **Qwen-VL** ✅ | 私有化/API | 中 | 性价比最高 |
| GPT-4V | API only | 高 | 数据安全风险 |
| GLM-4V | 私有化/API | 中 | 备选 |

## 已知缺口与优化路线图

### 当前缺失
- ❌ 图像预处理（倾斜校正、二值化、去噪）
- ❌ LLM 分类回退（关键词置信度低时）
- ❌ 置信度校准（边际分析）
- ❌ 解析结果持久化

### 路线图
| Phase | 内容 | 优先级 |
|-------|------|--------|
| 1 | 图像预处理 + 双路分类器 | P0 |
| 2 | LLM 集成 + 置信度校准 | P1 |
| 3 | 持久化 + PaddleOCR 对接 | P1 |
| 4 | 批量导入 + 自定义训练 | P2 |
