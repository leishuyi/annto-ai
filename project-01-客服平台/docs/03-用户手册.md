# 用户手册 — A2A 智能客服平台

## 工单处理全流程

## 第一步：创建工单

进入工单列表页，点击"新建工单"，填写：
- 客户名称（必填）
- 运单号
- 发件人 / 收件人 / 目的地
- 问题描述（必填）
- 货值（可选）

提交后工单状态为"待处理"。

## 第二步：执行 Agent 链路

在工单列表点击"执行 Agent"，系统自动执行6个 Agent：
1. 订单查询 → 查询物流状态
2. 单据录入 → 识别单据信息
3. 财务对账 → 比对发票实收
4. 调度校验 → 检查库存车辆
5. 风控检测 → 风险审查
6. 结论汇总 → 生成审核报告

执行完成后状态变为"待审核"。

## 第三步：查看 Agent 追溯

在工单详情页，可查看完整的 Agent 执行链路：
- 每个 Agent 的状态（完成/失败）
- 输入输出数据
- 置信度评分
- 执行耗时

## 第四步：人工授权

在工单详情页点击"进入人工授权"：
1. 查看 AI 建议摘要
2. 查看 Agent 处理链路
3. 选择操作：
   - ✅ 通过：确认 AI 建议
   - ❌ 驳回：填写驳回理由
   - ✏️ 修改后通过：修改金额后确认
4. 输入操作人姓名，提交

## API 测试命令

```bash
# 创建工单
curl -X POST http://localhost:8000/api/v1/tickets \
  -H "Content-Type: application/json" \
  -d '{"insured_name":"测试客户","insurance_product":"物流运输","incident_desc":"配送延迟","incident_date":"2026-07-24"}'

# 执行 Agent
curl -X POST http://localhost:8000/api/v1/tickets/1/run

# 查看追溯
curl http://localhost:8000/api/v1/tickets/1/traces

# 人工审核
curl -X POST http://localhost:8000/api/v1/tickets/1/review \
  -H "Content-Type: application/json" \
  -d '{"action":"approve","comment":"同意赔付","operator":"测试员"}'
```
