## 业务对齐分析

### 安得实际业务需求

安得智联的**安链通平台**是供应链决策的核心，技术路线明确为"AI 大模型 + 运筹优化算法 + 智能体仿真 + 数字孪生"：

| 业务需求 | 说明 | 优先级 |
|---------|------|--------|
| **供应链决策大模型** | 专家级方案输出，辅助供应链决策 | P0 |
| **运筹优化算法** | 多仓串提、动态路径优化（与上海交大合作）| P0 |
| **智能体仿真** | 场景推演验证，评估决策效果 | P0 |
| **多模态销量预测** | 生成式 AI 建模，为库存管理提供数据支撑 | P0 |
| **智能补调** | 自动补货计划，减少库存积压和缺货风险 | P0 |
| **对话式数据分析** | 已存在"小安 AI 引擎"，需对接而非重建 | P0 |
| **数字孪生** | 供应链场景仿真 | P1 |

## 技术选型（更新）

| 维度 | 原方案 | 修正方案 | 理由 |
|------|--------|---------|------|
| 核心定位 | NL2SQL + 对话问答 | **运筹优化 + 决策推理** | 匹配安链通路线 |
| 对话引擎 | 自建 | **对接小安 AI 引擎** | 安得已有能力，避免重建 |
| 运筹优化 | 无 | **OR-Tools / SCIP** | 多仓串提、路径优化 |
| 销量预测 | 简单移动平均 | **Prophet + LSTM → 生成式 AI** | 匹配安得多模态预测路线 |
| 仿真 | 3 个硬编码 | **蒙特卡洛 + 场景引擎** | 支持 what-if 推演 |
| 可观测性 | Prometheus | **博睿 Bonree ONE** | 复用安得现有 |
