# 用户手册 — 一线人员智能助手

## 司机端操作

### 导航规划
1. 输入出发点和目的地
2. 选择车型
3. 点击"规划路线"
4. 查看里程、时间、途经点

### 签收核验
1. 输入客户名称
2. 点击"核验签收"
3. 查看：签名匹配、公章检测、破损检测

### 话术助手
1. 输入客户说的话
2. 点击"生成话术"
3. 查看建议应答 + 情感标签

### 异常上报
1. 输入异常描述
2. 点击"提交上报"
3. 自动分类 + 判定优先级

## 运营端操作

### 财务对账
1. 输入对账周期
2. 点击"执行对账"查看匹配情况
3. 点击"差异分析"让 AI 分析原因

### 智能排班
1. 输入区域和日期
2. 点击"生成排班"
3. 查看司机分配表

### 异常看板
1. 点击"刷新预警"
2. 点击预警的"根因分析"
3. 查看 AI 分析结论

## API 测试

```bash
# 导航
curl -X POST http://localhost:8012/api/v1/driver/navigate \
  -H "Content-Type: application/json" \
  -d '{"origin":"佛山","destination":"上海"}'

# 签收
curl -X POST http://localhost:8012/api/v1/driver/signoff \
  -H "Content-Type: application/json" \
  -d '{"customer_name":"李强"}'

# 话术
curl -X POST http://localhost:8012/api/v1/driver/script \
  -H "Content-Type: application/json" \
  -d '{"customer_query":"货物怎么还没到？"}'

# 对账
curl -X POST http://localhost:8012/api/v1/ops/reconcile \
  -H "Content-Type: application/json" \
  -d '{"period":"2026-07"}'

# 排班
curl -X POST http://localhost:8012/api/v1/ops/schedule \
  -H "Content-Type: application/json" \
  -d '{"region":"华东","date":"2026-07-25"}'

# 预警
curl http://localhost:8012/api/v1/ops/alerts
```
