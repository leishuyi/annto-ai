## 2. 三种使用模式

| 模式 | 能力 | 示例问题 |
|------|------|---------|
| 🧠 决策推理 | 多 Agent 协同决策 | "华东区空调库存多少？下周怎么补货？" |

## 3. 决策推理

系统自动调用 3 个 Agent 协同推理：

```
问题输入
    ↓
库存 Agent → 查当前库存
在途 Agent → 查在途订单
预测 Agent → 查销量趋势
    ↓
LLM 合成 → 推荐方案
```

**示例问题：**
- "华东区空调库存多少？" → 查华东仓空调库存 2500 台
- "下周怎么补货？" → 结合库存+在途+预测，给出补货建议
- "华东和华南的库存对比" → 跨区域库存对比

## 4. 数据查询（NL2SQL）

用自然语言查询数据，自动转 SQL 并返回结果。

| 查询类型 | 示例 | 返回 |
|----------|------|------|
| 库存查询 | "华东区库存情况" | 库存表格 |
| 销售趋势 | "最近一周销售趋势" | 折线图数据 |
| 配送准时率 | "配送准时率" | 柱状图数据 |

## 5. 仿真推演

模拟假设场景对供应链的影响。

| 场景 | 输入示例 | 预期输出 |
|------|---------|---------|
| 📈 需求激增 | "如果销量增长30%" | 库存3天耗尽，建议提前补货 |
| 🌧️ 天气影响 | "华东降温10度" | 空调销量降15-20%，建议推迟补货 |
| ⛓️ 供应中断 | "供应商延迟5天" | SKU-AC-001缺货，影响1200台订单 |

## 6. API 速查

### 决策推理
```bash
curl -X POST http://localhost:8011/api/v1/decision/ask \
  -H "Content-Type: application/json" \
  -d '{"text":"华东区空调库存多少？"}'
```
预期返回：
```json
{"code": 0, "data": {
  "question": "华东区空调库存多少？",
  "region": "华东",
  "data": {"stock": {"total": 2500}, "forecast": {"avg_daily": 120}},
  "recommendation": "建议：华东区库存2500台..."
}}
```

### 数据查询
```bash
curl -X POST http://localhost:8011/api/v1/decision/nl2sql \
  -H "Content-Type: application/json" \
  -d '{"text":"华东区库存情况"}'
```

### 仿真推演
```bash
curl -X POST http://localhost:8011/api/v1/decision/simulate \
  -H "Content-Type: application/json" \
  -d '{"text":"需求激增30%"}'
```

### 查看 Agent
```bash
curl http://localhost:8011/api/v1/decision/agents
```

## 7. 常见问题排查

**Q: 问题返回空结果？**
A: 当前 mock 模式只支持有限的几个关键词（空调/冰箱、华东/华南/华北）。尝试使用预设示例问题。

**Q: 如何切换到真实数据？**
A: 设置 `.env` 中 `ANNTO_MOCK_MODE=false` 并配置 `ANNTO_LLM_API_KEY`。

**Q: NL2SQL 查不到想要的数据？**
A: 当前支持库存查询、销售趋势、配送准时率三种类型。其他类型会返回 unknown。
