# annto 多模态物流单据解析引擎 — 项目文档

## 概述
一套模型搞定物流场景所有纸质单据的结构化识别，覆盖运单、回单、仓储单、发票、证件5大类。

## 支持的单据类型

| 类型 | 说明 | 关键提取字段 |
|------|------|-------------|
| 运单(waybill) | 快递单、托运单 | 运单号、发件人、收件人、始发地、目的地、重量 |
| 回单(receipt) | 签收回单 | 签收人、签收日期、货物状态、破损备注 |
| 仓储单(warehouse_doc) | 入库/出库单 | SKU、数量、库位、经手人 |
| 发票(invoice) | 费用发票 | 发票号、金额、日期、开票方 |
| 证件(id_document) | 身份证、驾驶证 | 姓名、证件号、有效期 |

## 核心技术栈

| 组件 | 技术 | 状态 |
|------|------|------|
| OCR | PaddleOCR | MVP用mock |
| 多模态 | Qwen-VL | MVP用mock |
| 后端 | FastAPI | ✅ |
| 文档分类 | LLM + 关键词 | MVP用关键词 |
