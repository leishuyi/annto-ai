# 技术方案

## 双端架构

司机端(移动APP/Web)
├── 导航规划 → 对接城配调度平台(mock)
├── 签收核验 → 拍照→AI识别
├── 话术助手 → 客户问题→LLM建议
└── 异常上报 → 语音→自动填单→推送

运营端(Web后台)
├── RPA智能体 → 对账→分析→调整建议
├── 智能排班 → 订单→排班方案
└── 异常看板 → 聚合预警→根因分析

## API设计

所有接口使用 POST 方法，统一返回 ApiResponse 格式。
| 模块 | 接口 | 说明 |
|------|------|------|
| 导航 | /api/v1/driver/navigate | 路径规划 |
| 签收 | /api/v1/driver/signoff | 签收核验 |
| 话术 | /api/v1/driver/script | 话术生成 |
| 上报 | /api/v1/driver/report | 异常上报 |
| 对账 | /api/v1/ops/reconcile | 财务对账 |
| 分析 | /api/v1/ops/reconcile/analyze | 差异分析 |
| 排班 | /api/v1/ops/schedule | 智能排班 |
| 预警 | /api/v1/ops/alerts | 异常看板 |
| 根因 | /api/v1/ops/alerts/{id}/root-cause | 根因分析 |
