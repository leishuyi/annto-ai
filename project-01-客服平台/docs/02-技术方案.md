# 技术方案

## A2A 总体架构

## Agent 编排流程

1. 用户创建工单 → Case 状态变为 draft
2. 触发 Agent 链路 → status = processing
3. 串行执行 6 Agent：order_query → doc_intake → finance_recon → dispatch_check → risk_detection → summary
4. 全链路完成 → status = pending_review
5. 人工审核 → approved / rejected

## EventBus 事件流

- agent.completed: 每个 Agent 完成后发布
- case.pending_review: 全链路完成时发布
- 支持 fnmatch 模式订阅（如 agent.* 匹配所有 Agent 事件）

## 人工授权 Gate

强制节点：所有工单结论必须经人工确认，AI 仅生成审核建议。
