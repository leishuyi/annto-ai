# 用户手册 — 多模态物流单据解析引擎

## 解析流程

## 第一步：上传单据

打开单据解析页面，拖拽或点击上传单据影像：
- 支持格式：JPG / PNG / TIFF / PDF
- 单文件最大：10MB
- 系统自动判断文档类型

## 第二步：查看解析结果

解析完成后自动展示：
- 文档类型标签（运单/回单/仓储单/发票/证件）
- OCR 置信度进度条
- 字段提取表格
- 综合置信度评分
- OCR 原始文本（可展开）

## 第三步：结果处理

根据置信度分级策略：
| 置信度 | 处理方式 |
|--------|----------|
| > 95% | 自动写入系统 |
| 80% ~ 95% | 人工抽检 |
| < 80% | 强制人工录入 |

## API 测试

```bash
# 上传解析
curl -X POST http://localhost:8010/api/v1/documents/parse \
  -F "file=@test.jpg"

# 查看支持类型
curl http://localhost:8010/api/v1/documents/types
```
