# annto 供应链智能决策助手 — 项目文档

## 概述
三层架构：Agentic Reasoning + NL2SQL + 仿真推演，让供应链决策从"等BI报告"变为"对话式探索"。

## 三层能力

| 层 | 能力 | 示例 |
|----|------|------|
| Agentic Reasoning | 多Agent协同决策 | "华东区怎么补货？"→查库存+在途+预测→方案 |
| NL2SQL | 自然语言查数据 | "上月配送准时率？"→SQL→图表 |
| 仿真推演 | 假设场景分析 | "销量增长30%会怎样？"→模拟→影响评估 |

## 核心技术栈

| 组件 | 技术 | 状态 |
|------|------|------|
| 推理引擎 | DeepSeek-R1 | MVP用mock |
| Agent框架 | 自研ReasoningChain | ✅ |
| 数据 | mock供应链数据 | ✅ |
| 后端 | FastAPI | ✅ |
