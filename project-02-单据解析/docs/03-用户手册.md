## 2. 解析流程

```
上传单据影像
    ↓
文档分类器自动判断类型（运单/回单/仓储单/发票/证件）
    ↓
OCR 文字提取
    ↓
结构化字段提取
    ↓
输出解析结果（类型标签 + 字段表格 + 置信度）
    ↓
根据置信度分级处理
```

---

## 3. 支持的单据类型

| 类型 | 说明 | 提取字段 |
|------|------|---------|
| 📦 运单 | 快递单、托运单 | 运单号、发件人、收件人、始发地、目的地、重量、件数 |
| 📋 回单 | 签收回单 | 签收人、签收日期、货物状态、破损备注 |
| 🏭 仓储单 | 入库单、出库单 | SKU、数量、库位、经手人 |
| 🧾 发票 | 费用发票 | 发票号、金额、日期、开票方 |
| 🆔 证件 | 身份证、驾驶证 | 姓名、证件号、有效期 |

---

## 4. 置信度分级策略

| 置信度 | 颜色 | 处理方式 |
|--------|------|----------|
| > 95% | 🟢 高 | 自动写入系统 |
| 80% ~ 95% | 🟡 中 | 人工抽检 |
| < 80% | 🔴 低 | 强制人工录入 |

## 6. 常见问题排查

**Q: 解析失败返回 500？**
A: 检查上传文件格式是否在支持列表中（jpg/png/bmp/tiff/pdf），文件是否超过 10MB。

**Q: 识别字段不全？**
A: mock 模式只返回预设字段。接入真实 OCR 后准确率会提升。

**Q: 置信度低怎么办？**
A: 确保影像清晰、无遮挡、光线充足。扫描件优于拍照。

**Q: 如何测试？**
A: 使用 `curl` 上传测试图片，或用前端页面上传。
