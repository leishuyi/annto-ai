# annto 供应链智能决策助手 — 项目文档

## 概述
三层架构：Agentic Reasoning + NL2SQL + 仿真推演。让供应链决策从"等 BI 报告"变为"对话式探索"。

## 现状评估

**⚠️ 严重警告：当前为演示（Demo）级别，约 95% 代码为 mock，无生产价值。**

| 组件 | 当前 | 目标 |
|------|------|------|
| 库存 Agent | 4 行 Python dict | 对接 WMS/ERP |
| 在途 Agent | 2 行 mock 数据 | 对接 TMS |
| 预测 Agent | 简单移动平均 | ML 模型 |
| NL2SQL | 关键词匹配 | DeepSeek Text-to-SQL |
| 仿真 | 3 个硬编码场景 | 运筹优化引擎 |
| LLM | 4 个 if-return | DeepSeek API |

## 技术选型与方案对比

### LLM 推理引擎

| 方案 | 推理能力 | 成本 | 部署 | 结论 |
|------|---------|------|------|------|
| **DeepSeek-R1** ✅ | 强(671B MoE) | 低 | API/私有化 | 安得已接入，首选 |
| Qwen2.5-72B | 强 | 中 | 私有化 | 备选 |
| GPT-4o | 最强 | 高 | API only | 数据安全顾虑 |

### NL2SQL 方案

| 方案 | 准确率 | 复杂度 | 维护 | 结论 |
|------|--------|--------|------|------|
| **关键词匹配** ✅ | ~30% | 低 | 每新增需改代码 | MVP 演示用，无实用价值 |
| DeepSeek Text-to-SQL | ~85% | 低 | 零（只需 schema 描述） | 生产目标 |
| SQLNet / 专用 NL2SQL | ~90% | 高 | 需微调数据 | 长期演进 |

### 仿真引擎

| 方案 | 能力 | 复杂度 | 结论 |
|------|------|--------|------|
| **硬编码** ✅ | 3 个场景 | 零 | 当前演示状态 |
| 蒙特卡洛模拟 | 多场景概率分析 | 中 | 生产目标 |
| 数字孪生 | 全链路仿真 | 高 | 长期演进 |
