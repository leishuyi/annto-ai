# 用户手册 — 供应链智能决策助手

## 三种使用模式

## 模式一：决策推理

输入供应链问题，系统多 Agent 协同推理。示例问题：
- "华东区空调库存多少？"
- "下周华东怎么补货？"
- "华东和华南库存对比"

处理流程：问题分析 -> 库存查询 -> 在途查询 -> 预测分析 -> LLM 合成 -> 推荐方案

## 模式二：数据查询（NL2SQL）

用自然语言查询供应链数据。示例问题：
- "华东区库存情况"
- "最近一周销售趋势"
- "配送准时率"

## 模式三：仿真推演

模拟假设场景影响。示例场景：
- "销量增长30%会怎样？"
- "华东降温10度影响"
- "供应商延迟5天"

## 界面操作

1. 顶部切换三种模式
2. 输入框输入问题
3. 点击推荐问题快速体验
4. 查看结构化结果

## API 测试

```bash
# 决策推理
curl -X POST http://localhost:8011/api/v1/decision/ask \
  -H "Content-Type: application/json" \
  -d '{"text":"华东区空调库存多少？"}'

# 数据查询
curl -X POST http://localhost:8011/api/v1/decision/nl2sql \
  -H "Content-Type: application/json" \
  -d '{"text":"华东区库存情况"}'

# 仿真推演
curl -X POST http://localhost:8011/api/v1/decision/simulate \
  -H "Content-Type: application/json" \
  -d '{"text":"需求激增30%"}'
```
