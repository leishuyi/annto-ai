# annto A2A 智能客服平台 — 项目文档

## 项目概述
面向安得智联物流场景的 A2A 多智能体客服平台，覆盖订单查询、单据录入、财务对账、调度校验、风控检测到结论汇总的全链路自动化。

## 6-Agent 链路

| Agent | 功能 | 输出 |
|-------|------|------|
| 订单查询 | 查询物流订单状态、跟踪信息 | 运单号、收发件人、当前位置 |
| 单据录入 | 识别运单/回单等单据信息 | 录入确认、货物清单 |
| 财务对账 | 发票与实收金额比对 | 差异分析、对账结论 |
| 调度校验 | 检查库存、车辆、路线可行性 | 调度建议、发车时间 |
| 风控检测 | 地址一致性、收件人核实、货物价值 | 风险评分、风控建议 |
| 结论汇总 | 聚合全链路结果，生成客服回复 | 汇总报告、操作建议 |

## 技术选型与方案对比

### 后端框架选型

| 方案 | 性能 | 生态 | 学习成本 | 结论 |
|------|------|------|---------|------|
| **FastAPI** ✅ | async 原生，~10K req/s | 丰富，Pydantic v2 集成 | 低 | 选型理由：原生 async 支持、自动 OpenAPI 文档、类型安全 |
| Flask | 同步，~3K req/s | 最丰富 | 极低 | 淘汰理由：无原生 async，大并发需额外方案 |
| Django Ninja | async 支持，~8K req/s | 较少 | 中 | 淘汰理由：过度设计，ORM 锁定 |

### Agent 通信协议选型

| 方案 | 延迟 | 持久化 | 运维成本 | 结论 |
|------|------|--------|---------|------|
| **进程内 dataclass** ✅ | < 1μs | ❌ | 零 | MVP 阶段，生产需升级 |
| Redis Streams | < 1ms | ✅ | 中 | 生产环境目标 |
| RabbitMQ | < 5ms | ✅ | 中 | 可替代方案 |
| gRPC | < 1ms | ❌ | 高 | 跨语言/跨进程时使用 |
| **决策**：MVP 用进程内 dataclass，生产用 Redis Streams + Celery |

### 认证方案选型

| 方案 | 实现成本 | 安全性 | 可扩展 | 结论 |
|------|---------|--------|--------|------|
| **API Key** ✅ | 低 | 中 | 低 | MVP 阶段 |
| JWT Bearer | 中 | 高 | 高 | ✅ 生产目标 |
| OAuth2 + OIDC | 高 | 最高 | 高 | 企业 SSO 集成时 |
| **决策**：MVP 用 API Key，生产迁移到 JWT + RBAC |

### 数据库选型

| 方案 | 并发能力 | 向量支持 | 运维成本 | 结论 |
|------|---------|---------|---------|------|
| **SQLite** ✅ | 单写 | ❌ | 零 | 仅开发 |
| **PostgreSQL** 🎯 | 高 | ✅ pgvector | 中 | ✅ 生产目标 |
| MySQL 8.0 | 高 | ❌ | 中 | 备选 |
| **决策**：开发用 SQLite，生产必须切换到 PostgreSQL |

## 架构决策记录（ADR）

| ADR | 决策 | 日期 | 理由 |
|-----|------|------|------|
| 001 | 采用分层 + 事件驱动架构 | 2026-07 | Agent 间解耦，EventBus 支持跨 Agent 通知 |
| 002 | Agent 串行编排 + 可选并行 | 2026-07 | 默认串行保证数据一致性，feature flag 控制并行 |
| 003 | 人工授权 Gate 为强制节点 | 2026-07 | AI 仅生成建议，最终决定权在人工 |
| 004 | 同步编排 → 目标异步 Celery | 2026-07 | 当前同步为 MVP 速度，真实 LLM 下必须异步 |

## 优化路线图

### Phase 1（基础设施）
- PostgreSQL 替换 SQLite
- Celery 异步任务队列
- JWT 统一认证

### Phase 2（核心能力）
- Agent 并行化（C‖D 并行执行）
- 状态机增加 FAILED 状态
- EventBus 升级到 Redis Streams

### Phase 3（生产加固）
- Prometheus + Grafana 可观测性
- 全链路 OpenTelemetry 追踪
- 单元测试覆盖 > 80%
