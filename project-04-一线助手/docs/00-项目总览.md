# annto 一线人员智能助手 — 项目文档

## 概述
双端设计：司机端(移动APP) + 运营端(Web后台)，覆盖配送全链路的智能化。

## 双端能力

| 端 | 模块 | 说明 |
|----|------|------|
| 司机端 | 智能导航 | 路径规划、实时路况 |
| 司机端 | 签收核验 | 签名匹配、破损检测 |
| 司机端 | 话术助手 | 客户异议应答建议 |
| 司机端 | 异常上报 | 语音→自动填单 |
| 运营端 | RPA对账 | 发票差异分析+调整建议 |
| 运营端 | 智能排班 | 基于订单的自动排班 |
| 运营端 | 异常看板 | 实时预警+根因分析 |

## 核心技术栈

| 组件 | 技术 | 状态 |
|------|------|------|
| 后端 | FastAPI | ✅ |
| LLM | DeepSeek-R1(mock) | MVP用mock |
| 前端 | React + Ant Design | ✅ |
| 端侧 | 预留轻量模型接口 | 后续接入 |
