# 核心功能设计

## 司机端模块

### 导航规划
- 输入：起止地点+车型
- 输出：途经点、总里程、预计时间、交通延迟
- 后续对接：城配智能调度平台

### 签收核验
- 签名匹配：OCR比对签名一致性
- 公章检测：识别签收回单上的公章
- 破损检测：图像识别货物破损

### 话术助手
- 5种场景：延迟、破损、安装、退货、投诉
- 情感识别：positive/neutral/negative
- LLM生成建议话术

### 异常上报
- 语音转文本填单
- 自动分类问题类型
- 自动判定优先级

## 运营端模块

### RPA智能体
- 对账：发票vs实收批量比对
- 差异分析：LLM分析差异原因
- 调整建议：自动生成调账方案

### 智能排班
- 按区域+日期自动排班
- 考虑司机偏好、车辆容量、时间窗口

### 异常看板
- 实时聚合多类型预警
- LLM根因分析
- 自动推荐解决方案
