# P4 一线人员智能助手 — 架构审查

> 审查日期：2026-07-24 | 审查人：资深架构师

## 业务对齐分析

### 安得实际业务需求

安得智联拥有 **73,000~77,000 名司机及送装工程师**，年最后一公里送装一体 **2,720 万单**，一线助手是刚需：

| 业务需求 | 说明 | 优先级 |
|---------|------|--------|
| 导航调度 | 配送路径规划，支持货车路线 | P0 |
| 签收核验 | 拍照上传 + OCR 签名识别 + 破损检测 | P0 |
| 送装一体 | 家电/家居安装服务管理（2,720 万单/年）| **P0** |
| 异常上报 | 配送异常拍照 + 语音描述 + 自动分类 | P0 |
| RPA 财务对接 | 回单/发票对接财务系统（SAP/金蝶/用友） | P0 |
| 智能排班 | 司机排班 + 车辆调度优化 | P0 |
| 预警推送 | 主动推送异常事件 | P0 |
| **离线能力** | 配送途中网络不稳定，需离线操作 | **P0** |

class OfflineEngine:
    """
    Service Worker + IndexedDB 离线策略：
    1. 启动时同步全量数据到本地
    2. 在线时走 API，同时更新本地缓存
