## 1. 快速上手

| 项 | 值 |
|---|---|
| 后端地址 | `http://localhost:8012` |
| API 文档 | `http://localhost:8012/docs` |
| 健康检查 | `http://localhost:8012/api/v1/health` |
| 前端地址 | `http://localhost:5173` |

### 一键启动

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8012

# 前端（可选）
cd frontend
npm install && npm run dev
```

## 2. 司机端操作

### 2.1 🚚 导航规划

1. 输入**出发点**（如"佛山"）
2. 输入**目的地**（如"上海"）
3. 选择车型（轻卡/面包车）
4. 点击"规划路线"

输出：途经点列表、总里程、预计时间、交通延迟

### 2.2 📝 签收核验

1. 输入客户名称
2. 点击"核验签收"

输出：签名匹配（✅/❌）、公章检测（有/无）、破损检测（有/无）、置信度

### 2.3 💬 话术助手

1. 输入客户说的话（如"货物怎么还没到？"）
2. 点击"生成话术"

输出：建议应答话术 + 情感标签（positive/neutral/negative）

**5 种预设场景：**

| 场景 | 客户说 | 建议回复 |
|------|--------|---------|
| 投诉 | "你们物流太差了！" | 安抚+记录+2小时跟进 |
| 延迟 | "怎么还没到？" | 解释拥堵+预计30min |
| 破损 | "箱子都破了" | 指导拍照+48h理赔 |
| 退货 | "我要退回去" | 确认流程+安排取件 |
| 安装 | "管安装吗？" | 确认含安装服务 |

### 2.4 ⚠️ 异常上报

1. 输入异常描述
2. 点击"提交上报"

系统自动：分类问题类型 + 判定优先级 + 生成描述

| 关键词 | 问题类型 | 优先级 |
|--------|---------|--------|
| 破损/损坏 | goods_damage | high |
| 迟到/延迟 | delivery_delay | medium |
| 地址/送错 | wrong_address | high |
| 其他 | other | low |

## 3. 运营端操作

### 3.1 💰 财务对账

1. 输入对账周期（如 `2026-07`）
2. 点击"执行对账" → 查看匹配情况
3. 点击"差异分析" → AI 分析差异原因

### 3.2 📅 智能排班

1. 输入区域（如"华东"）
2. 点击"生成排班"
3. 查看司机分配表

### 3.3 🚨 异常看板

1. 点击"刷新预警" → 查看实时预警列表
2. 点击预警的"根因分析" → AI 分析原因和建议

| 预警类型 | 级别 | 根因 |
|---------|------|------|
| delivery_delay | ⚠️ warning | 浦东修路绕行 |
| inventory | 🔴 critical | 销量超预期+工厂延迟 |
| damage | ℹ️ info | 正常范围 |

## 4. API 速查

### 导航规划
```bash
curl -X POST http://localhost:8012/api/v1/driver/navigate \
  -H "Content-Type: application/json" \
  -d '{"origin":"佛山","destination":"上海","vehicle_type":"轻卡"}'
```

### 签收核验
```bash
curl -X POST http://localhost:8012/api/v1/driver/signoff \
  -H "Content-Type: application/json" \
  -d '{"customer_name":"李强"}'
```

### 话术助手
```bash
curl -X POST http://localhost:8012/api/v1/driver/script \
  -H "Content-Type: application/json" \
  -d '{"customer_query":"货物怎么还没到？"}'
```

### 异常上报
```bash
curl -X POST http://localhost:8012/api/v1/driver/report \
  -H "Content-Type: application/json" \
  -d '{"voice_text":"箱子破损","location":"上海浦东"}'
```

### 财务对账
```bash
curl -X POST http://localhost:8012/api/v1/ops/reconcile \
  -H "Content-Type: application/json" \
  -d '{"period":"2026-07"}'
```

### 智能排班
```bash
curl -X POST http://localhost:8012/api/v1/ops/schedule \
  -H "Content-Type: application/json" \
  -d '{"region":"华东","date":"2026-07-25"}'
```

### 异常看板
```bash
# 获取预警
curl http://localhost:8012/api/v1/ops/alerts

# 根因分析
curl -X POST http://localhost:8012/api/v1/ops/alerts/1/root-cause
```

## 5. 常见问题排查

**Q: 导航路线不准确？**
A: 当前为 mock 数据。对接城配调度平台后可获取真实路线。

**Q: 签收核验怎么测试？**
A: 输入任意客户名称即返回 mock 结果。真实 OCR 需接入 PaddleOCR。

**Q: 对账差异分析结果简单？**
A: MVP 使用 mock LLM。接入 DeepSeek 后分析会更深入。

**Q: 话术助手的回复不对？**
A: 确认客户输入是否包含关键词。当前支持 5 种场景。

**Q: 如何重置测试数据？**
A: 重启后端即可（mock 数据在内存中）。
