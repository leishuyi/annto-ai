# 核心功能设计

## Agent 详解

### 订单查询 Agent
- 输入：case_id
- 对接模拟系统：鲲鹏物流
- 输出：运单号、收发件人、目的地、当前位置、预计到达

### 单据录入 Agent
- 模拟运单/回单识别
- 输出：运单号、货物描述、总重量、总件数

### 财务对账 Agent
- 发票金额 vs 实收金额比对
- 输出：差异额、差异原因、对账状态

### 调度校验 Agent
- 库存可用性、车辆可用性、路线可行性
- 输出：建议车型、预计配送天数

### 风控检测 Agent
- 地址一致性、收件人核实、货物价值合理性
- 输出：风险评分、风险等级、风控建议

### 结论汇总 Agent
- 聚合前 5 个 Agent 输出
- 生成客服建议和可追溯审计轨迹

## 人工授权工作台

提供通过/驳回/修改后通过三种操作，所有操作记入审计日志。
